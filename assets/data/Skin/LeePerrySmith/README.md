# Lee Perry-Smith Head Scan Assets

This sample uses the Lee Perry-Smith / Infinite-Realities head scan as a PreintegratedSkin test asset.

Source package:
https://casual-effects.com/g3d/data10/research/model/lpshead/lpshead.zip

Attribution:
Original scan data by Lee Perry-Smith / I-R Entertainment Ltd. Converted by Morgan McGuire and Guedis Cardenas. The Unity-oriented InfiniteScan package by Keijiro Takahashi was also used as a licensing cross-check.

Generated helper maps in this directory:

- `normal.png` generated from `bump-lowRes.png`
- `roughness.png` generated from `lambertian.jpg`
- `metallic.png` generated as a zero-metalness map
- `subsurface_color.png` generated as a red-biased skin subsurface color map from `lambertian.jpg`
- `PreintegratedSkinBRDF_Color.png` generated as a Penner/UE-style preintegrated skin lookup table for this sample
